### 위키

위키는 {{WIKI_URL}} 의 Outline 이고, MCP 서버 `{{MCP_SERVER_NAME}}` 으로 접근한다. 그 서버의 도구(`list_collections`, 검색, 읽기, 생성, 수정)를 쓴다. 콜렉션은 정확한 이름으로 찾고, 콜렉션 id나 문서 id를 하드코딩하지 않는다.

### 세션 기록: `{{SESSIONS_COLLECTION}}`

`{{SESSIONS_COLLECTION}}` 에는 너만 쓴다. 이 콜렉션의 설명(overview)이 원본 규정이다. 세션마다 첫 쓰기 전에 한 번 읽고, 이 블록과 다르면 overview를 따른다.

- **메인 세션만 기록한다.** 다른 세션이 띄운 서브에이전트나 Worker로 돌고 있다면 위키에 쓰지 않고, 너를 띄운 세션에 보고한다.
- **작업 1건당 문서 1개.** 세션과 머신이 바뀌어도 같은 작업이면 같은 문서에 이어 쓴다. 새 문서를 만들기 전에 반드시 `{{SESSIONS_COLLECTION}}` 에서 같은 작업의 문서를 검색하고, 맞는 문서가 없을 때만 만든다. 중복 생성은 금지다.
- **제목:** `YYYY-MM-DD · <작업 요약>`. 날짜는 작업을 시작한 날의 현지 날짜다. 도구가 지원하면 문서 `icon` 필드에 주제 이모지 1개를 넣는다.
- **문서 골격:**
  - 첫 줄: `작성자: {{AGENT_NAME}}` 와 상태. 🟡 진행 중 / ✅ 완료 / 🔴 차단됨 / ⚪ 대기 / ⚫ 취소
  - `## 배경`
  - `## 완료 조건`
  - `## Update — <YYYY-MM-DD HH:MM TZ> · <머신>` 을 의미 있는 진행, 방향 전환, blocker마다 append 한다(`<머신>` 은 짧은 호스트 이름, `hostname -s`)
  - 작업이 끝나면 `## 완료 기록` 과 검증 근거(수치, 경로, 커밋 해시, 링크, 명령 출력)
  - 마지막 줄: `최종 갱신: {{AGENT_NAME}} · <YYYY-MM-DD HH:MM TZ>`
- **본문 서명이 유일한 저자 표기다.** 위키의 작성자(createdBy) 필드에는 로그인이나 API 토큰의 소유자가 찍힌다. 본문의 `작성자:` 줄과 말미 서명만이 저자 기록이므로 생략하지 않는다.
- **기록 시점:** 작업을 시작할 때 문서를 만들거나 기존 문서에 재개 Update를 붙이고, 중요한 진행과 blocker마다 Update를 append 하고, 끝나면 완료 기록을 쓰고 상태를 바꾼다.
- **flat으로 유지한다.** `{{SESSIONS_COLLECTION}}` 에 하위 문서를 만들지 않는다.
- **비밀값은 절대 기록하지 않는다.** API key, 토큰, 비밀번호, OAuth secret은 위키에 쓰지 않는다. 저장 경로, 변수명, last4까지만 쓴다.
- 사용자가 달리 요청하지 않으면 사용자의 언어로 쓴다. 명령어, 경로, 기술 용어는 원문 그대로 둔다.

### 공유 지식: `{{SHARED_COLLECTION}}`

`{{SHARED_COLLECTION}}` 은 모든 에이전트가 읽고 쓴다. 사용자의 선호, 프로젝트, 컨벤션, 결정, 환경처럼 오래 가는 사실을 정제해서 담는다. 첫 쓰기 전에 overview를 읽는다.

- **먼저 찾아본다.** 사용자의 선호, 프로젝트, 컨벤션을 사용자에게 묻기 전에 `{{SHARED_COLLECTION}}` 을 검색한다. 답이 있으면 그걸 쓰고 문서 링크를 인용한다.
- **로그가 아니라 정제된 사실을 쓴다.** 오래 갈 사실을 알게 되면 맞는 기존 문서에 더하거나(먼저 검색한다) 주제 하나짜리 문서를 만든다. 세션 로그, 진행 메모, 대화 기록은 여기에 절대 쓰지 않는다. 그건 `{{SESSIONS_COLLECTION}}` 에 쓴다.
- **수정 표시를 남긴다.** 고칠 때마다 끝에 `수정자: {{AGENT_NAME}} · <YYYY-MM-DD>` 줄을 새로 붙인다. 이전 줄은 지우지 않는다.
- **갈라 쓰지 말고 고친다.** 사실이 낡았으면 그 자리에서 고치고 무엇이 바뀌었는지 적는다. 기존 문서와 모순되는 두 번째 문서를 만들지 않는다.
- 여기에도 비밀값은 쓰지 않는다.

### 다른 에이전트

- 다른 에이전트는 각자의 `<이름> Sessions` 콜렉션에 쓴다. 읽는 것은 되지만 고치지 않는다.
- 다른 에이전트의 문서에 기대어 판단했으면 그 링크를 인용한다. 거기서 오류를 찾으면 사용자에게 알리거나 공유 사실을 `{{SHARED_COLLECTION}}` 에서 고치고, 그 문서 자체는 건드리지 않는다.

### 기록하지 않아도 되는 경우

잡담, 단순 질의응답, 가벼운 조회는 세션 문서를 만들지 않아도 된다. 목표가 있거나 여러 단계를 거치거나 나중에 누군가 결과를 찾을 작업을 기록한다.

### 위키에 닿지 않을 때

`{{MCP_SERVER_NAME}}` 이 실패하거나 없으면(연결 안 됨, 로그인 만료, 위키 다운) 사용자에게 한 줄로 알리고 작업은 계속한다. 서버가 돌아오면 쓸 수 있게 Update 내용을 대화에 남겨 둔다(`/mcp` 에서 연결 상태를 보고 다시 로그인한다). REST API를 직접 호출해 우회하지 않고, 그러려고 설정 파일에서 토큰이나 키를 복사하지 않는다.
